# Django Core Tracker

**Django Core Tracker**, standart bir yapılacaklar listesinin ötesinde, operasyonel süreçlerin merkezi bir yapıda takip edilebilmesi için tasarlanmış bir Django projesidir. Temel veri tabanı işlemlerini temiz bir mimariyle sunarken, ileride API servislerine, yetkilendirme modüllerine veya daha büyük kurumsal sistemlere kolayca entegre edilebilecek şekilde ölçeklenebilir kurgulanmıştır.
